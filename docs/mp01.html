Data Acquisition

#' Acquire Netflix What We Watched Reports
#' 
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash). 
#' 
#' After import, files are stacked vertically and some basic cleaning is
#' performed. 
load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 6, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event)
}

The data contain 61,892 title-period observations across 11 columns. Column types are correct after cleaning: titles and periods are character, dates are Date, flags are logical, and viewership measures are numeric. Two quirks stand out: views are missing for early periods (Netflix changed its reporting over time), and runtime is missing for some titles, so analyses using those columns must handle missing values.

Exploratory Questions

  1. The dataset covers the period from 2023-01-01 to 2026-06-30 — seven half-year reporting windows from 2023H1 through 2026H1.

  2. The dataset contains 24,427 distinct titles, counting each season as a separate title (for example, Stranger Things 2 and Stranger Things 3).

  3. Bridgerton titles accumulated 4,862,800,000 hours viewed (about 4.9 billion hours) across all periods.

  4. Stranger Things titles accumulated 5,548,500,000 hours viewed (about 5.5 billion hours), excluding the companion show Beyond Stranger Things, the animated spin-off Tales from ’85, and the fireplace special.

  5. In 2026H1, the top 10 titles captured 6.7% of total watch time.

  6. About 35.1% of titles are available globally, but those titles account for 52.1% of total hours viewed — globally available content punches well above its weight.

Concentration of viewership (Gini coefficient)

gini_coef <- function(x) {
  x <- x[!is.na(x) & is.finite(x)]
  n <- length(x)
  x <- sort(x)
  (2 * sum(seq_len(n) * x) / (n * sum(x))) - (n + 1) / n
}

gini_raw <- gini_coef(NETFLIX_DATA$hours_viewed)
gini_norm <- gini_coef(NETFLIX_DATA$hours_viewed / NETFLIX_DATA$runtime)

tibble::tibble(
  measure = c("Hours viewed", "Hours viewed per minute of runtime"),
  gini = c(gini_raw, gini_norm)
) |>
  gt::gt() |>
  gt::cols_label(measure = "Measure", gini = "Gini Coefficient") |>
  gt::fmt_number(columns = gini, decimals = 2)
Measure Gini Coefficient
Hours viewed 0.77
Hours viewed per minute of runtime 0.71

The Gini coefficient is a number between 0 and 1 that measures how unequally viewing is spread across titles: 0 would mean every title gets exactly the same watch time, while 1 would mean a single title gets all of it. On raw hours viewed, the Gini coefficient is 0.77, and after normalizing by title runtime it is 0.71 — normalizing barely changes the picture, so concentration is not just an artifact of longer titles. Viewing is heavily concentrated among a minority of titles. Yet no single title dominates: the top title in each period captures only about 1% of that period’s hours. The concentration comes from a long tail of titles that hardly anyone watches, not from a winner-take-all hit.

Strategy Memo

To: Netflix Co-CEOs and Content Leadership
From: Meng Sun, Content Strategy
Date: October 16, 2026
Re: Netflix Content Strategy for 2027 and Beyond

I looked at seven reports to understand what people watch on Netflix and which types of shows get more views. The data includes 24,427 titles and 511,590,500,000 hours of viewing, from 2023-01-01 to 2026-06-30. After looking at the results, I found three main things Netflix should focus on in 2027: keeping popular shows, getting more worldwide rights, and spending money more carefully.

Bridgerton got 4,862,800,000 hours of viewing, or about 4.9 billion hours, while Stranger Things got 5,548,500,000 hours, or about 5.5 billion hours. These shows are very popular, but together they only account for 2.0% of total viewing. The most popular individual title accounts for only 1.4%, and the Gini score is 0.77. This suggests that viewers watch many different shows instead of depending on just one or two. Older shows like Suits and Breaking Bad also continue to get views, with each title getting at least 74,900,000 hours in the periods measured. Many of these shows are licensed, which shows that Netflix does not always need to make new shows to give viewers something they enjoy.

I think Netflix should continue investing in two or three major franchises because they already have fans and can attract attention when new seasons come out. However, spending money on original shows does not guarantee that they will become popular. Netflix should consider using some of its budget to get the rights to older shows that people already enjoy watching. This would give viewers more choices and help Netflix keep its library interesting. In my opinion, having a mix of popular original shows and older licensed shows is a better plan than depending too much on new releases.

Another finding is that only 35.1% of titles are available worldwide, but they account for 52.1% of total viewing hours. On average, a title available worldwide gets 2 times as many viewing hours as a title only available in certain regions. I think Netflix should pay more attention to this because a show that is popular in one country might also attract viewers in other countries. Netflix should try to get worldwide rights when buying new shows. It should also look at regional shows that perform well and consider making them available globally. This could help Netflix reach more viewers without always needing to create new content.

Live content is another area Netflix should consider carefully. Live content gets an average of 3,560,000 viewing hours, compared with 8,289,547 for regular recorded content. Among the top 10 titles, live content gets 36,660,000 hours compared with 791,400,000 hours for recorded content, a difference of about 22 times. These results suggest that big live events can attract a lot of viewers. However, I do not think Netflix should spend money on every type of live program. It should focus on major events that people have a reason to watch live and use the rest of its budget for popular franchises and content that can reach viewers worldwide.

Overall, I think Netflix should offer a wide selection of content instead of depending on only a few popular shows. For 2027, I recommend keeping a few strong franchises, getting worldwide rights to more shows, and choosing live events carefully. This would give viewers more options and help Netflix spend its budget more wisely.
