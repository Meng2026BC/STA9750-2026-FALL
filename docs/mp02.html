Author

Meng Sun

Introduction

The Green Transit Alliance (GTA) is a fictional coalition of green transit advocates, and I’m writing this as its director. Our goal is to figure out which transit systems in the U.S. are actually environmentally responsible, not just the ones that look good on paper. To do this, I pulled together three datasets: the EIA state electricity profiles, the 2025 NTD energy consumption data, and the 2025 NTD service data. The basic method is to convert every fuel an agency uses (including the electricity it pulls from the grid) into pounds of CO₂, divide by passenger miles, and rank the agencies from cleanest to dirtiest. All of this leads up to the press release at the end, where I announce the GTA’s 2025 awards.

get_eia_sep <- function(state, abbr){
    library(tidyverse)
    library(stringr)
    library(httr2)
    library(rvest)
    library(fs)

    state_formatted <- str_to_lower(state) |> str_replace_all("\\s", "")

    dir_name <- fs::path("data", "mp02")
    file_name <- fs::path(dir_name, state_formatted)

    fs::dir_create(dir_name, recurse=TRUE)

    if(!fs::file_exists(file_name)){
        BASE_URL <- "https://www.eia.gov"
        RESPONSE <- request(BASE_URL) |>
          req_url_path("electricity",
                       "state",
                       state_formatted) |>
          req_headers(
            `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
            ) |>
          req_retry(
                max_tries = 4,
          ) |>
          req_perform(file_name)

        resp_check_status(RESPONSE)
    }

    TABLE <- read_html(file_name) |>
        html_element("table") |>
        html_table() |>
        mutate(Item = str_to_lower(Item))

    if("U.S. rank" %in% colnames(TABLE)){
        TABLE <- TABLE |> rename(Rank = `U.S. rank`)
    }

    CO2_MWh <- TABLE |>
        filter(Item == "carbon dioxide (lbs/mwh)") |>
        pull(Value) |>
        str_replace_all(",", "") |>
        as.numeric()

    PRIMARY <- TABLE |>
        filter(Item == "primary energy source") |>
        pull(Rank)

    RATE <- TABLE |>
        filter(Item == "average retail price (cents/kwh)") |>
        pull(Value) |>
        as.numeric()

    GENERATION_MWh <- TABLE |>
        filter(Item == "net generation (megawatthours)") |>
        pull(Value) |>
        str_replace_all(",", "") |>
        as.numeric()

    data.frame(CO2_MWh               = CO2_MWh,
               primary_source        = PRIMARY,
               electricity_price_MWh = RATE * 10,
               generation_MWh        = GENERATION_MWh,
               state                     = state,
               abbreviation              = abbr
    )
}

EIA_SEP_REPORT <- map2(state.name, state.abb, get_eia_sep) |> list_rbind()

load_ntd_energy <- function(){
  library(readxl)
  library(httr2)
  library(tidyverse)
  library(fs)

  # Create 'data/mp02' directory if not already present
  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse=TRUE)

  NTD_ENERGY_FILE <- fs::path(DATA_DIR, "2025_ntd_energy.xlsx")

  if(!fs::file_exists(NTD_ENERGY_FILE)){
    library(httr2)
    request("https://www.transit.dot.gov/") |>
      req_url_path("sites",
                   "fta.dot.gov",
                   "files",
                   "2026-09",
                   "2025 Energy Consumption_260806.xlsx") |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0") |>
      req_perform(NTD_ENERGY_FILE)
  }

  if(file.info(NTD_ENERGY_FILE)$size < 1e4){
        cat("I was unable to download the NTD Energy File. Please try again.\n")
        stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_energy.xlsx')` and try again.")
    }

  to_numeric_fill_0 <- function(x){
    x <- if_else(x == "-", NA, x)
    replace_na(as.numeric(x), 0)
  }

  read_excel(NTD_ENERGY_FILE) |>
    select(-c(`Reporter Type`,
              `Reporting Module`,
              `Gallons of Other Fuel`,
              `Other Fuel Description`)) |>
    mutate(across(-c(`Agency Name`,
                     `Mode`,
                     `TOS`),
                  to_numeric_fill_0)) |>
    group_by(`NTD ID`, `Mode`, `Agency Name`) |>
    summarize(across(where(is.numeric), sum),
              .groups = "keep") |>
    mutate(ENERGY = sum(c_across(c(where(is.numeric))))) |>
    filter(ENERGY > 0) |>
    select(-ENERGY) |>
    ungroup()
}

load_ntd_service <- function(){
  library(httr2)
  library(tidyverse)
  library(fs)

  # Create 'data/mp02' directory if not already present
  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse=TRUE)

  NTD_SERVICE_FILE <- fs::path(DATA_DIR, "2025_ntd_service.csv")

  if(!fs::file_exists(NTD_SERVICE_FILE)){
    library(httr2)
    request("https://data.transportation.gov/resource/4fir-qbim.csv") |>
      req_url_query(`$query`=paste(
        "SELECT  `_5_digit_ntd_id` AS `NTD_ID`",
        "`max_agency` AS `AGENCY`",
        "`max_reporter_type` AS `reporter_type`",
        "`max_organization_type` AS `organization_type`",
        "`max_city` AS `city`",
        "`max_state` AS `state`",
        "`mode`",
        "`type_of_service`",
        "`max_primary_uza_code` as `uza_code`",
        "`max_primary_uza_name` as `uza_name`",
        "`max_primary_uza_area_sq_miles` as `uza_sq_miles`",
        "`max_primary_uza_population` as `uza_population`",
        "`max_service_area_sq_miles` as `service_area_sq_miles`",
        "`max_service_area_population` as `service_area_population`",
        "`questionable_record` as `flagged_likely_inaccurate`",
        "`sum_unlinked_passenger_trips_upt` as `total_upt`",
        "`sum_passenger_miles` WHERE caseless_one_of(`report_year`, '2025') limit 50000",
        sep=",")) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0") |>
      req_perform(NTD_SERVICE_FILE)
  }

  if(file.info(NTD_SERVICE_FILE)$size < 1e4){
        cat("I was unable to download the NTD Service File. Please try again.\n")
        stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_service.xlsx')` and try again.")
    }

  read_csv(NTD_SERVICE_FILE) |>
    mutate(flagged_likely_inaccurate = !is.na(flagged_likely_inaccurate))
}

Deliverable: Transit Award “Press Release”

Task 8: Final Deliverable

FOR IMMEDIATE RELEASE

Green Transit Alliance Announces the 2025 Transit Awards

As director of the Green Transit Alliance, I’m excited to announce our 2025 award winners. We ranked 2,241 transit agencies across the country using one simple metric: how many pounds of CO₂ an agency produces for every passenger mile it carries.

Greenest Transit Agency

How we calculated it. For each agency, we took its total CO₂ in pounds, converted its fuels using EIA emission factors, counted its electricity at its state’s grid rate, and divided by passenger miles. We split agencies into three size classes by ridership (747 agencies in each) so the big systems and the tiny ones aren’t competing against each other. This makes the comparison fairer because a small vanpool service shouldn’t have to compete directly with a huge subway system.

Large: Seattle Center Monorail, 0.064 lb CO₂ per passenger mile. The monorail is fully electric and runs on Washington’s grid, which is only 249 lb per MWh because so much of it comes from hydropower.

Medium: Pima Association of Governments (vanpool), 0.138.

Small: Nebraska Department of Transportation (vanpool), 0.266.

Putting it in perspective: the median agency comes in at 1.04, so Seattle is about 16× cleaner than a typical system. Our two vanpool winners also had something interesting in common: their average trips were around 46 to 49 miles. Longer trips may help spread emissions across more passenger miles. Apparently, sometimes the greener choice isn’t a bigger vehicle, but a smaller one carrying people efficiently.

The Worst Of: The “Are We There Yet? Oh, We Are” Award

Our not-so-proud winner this year is Plaquemines Port, Louisiana Gateway Port, a ferry in Louisiana, at 23.5 lb CO₂ per passenger mile. That’s about 23× the median agency.

Here’s how it happened. The ferry burned 246,932 gallons of diesel and put out 5.54 million pounds of CO₂ while carrying 471,854 trips. But the average trip is only 0.5 miles. That’s basically a river crossing, so it works out to about 12 pounds of CO₂ per trip for a ride that’s shorter than the walk to the dock.

To be fair, the ferry is probably the only practical way for many people to cross that river, and people clearly rely on it. It’s not necessarily a bad transit service; it just has a difficult time winning an emissions-per-mile competition. If we gave awards for the most dramatic use of diesel over the shortest distance, this ferry would definitely take home the trophy. For now, its prize is a trophy made of empty diesel jugs.

Congratulations, I guess!
